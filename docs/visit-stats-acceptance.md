2026-11-17，仅修改指定备份站点，未提交、推送或部署。修改前文件备份位于 `/tmp/takina-footer-visits-before/`。

在现有页脚最后加入今日和累计页面访问次数（PV），使用不蒜子共享计数，支持中英文、浅深色和手机布局。按导航计数，刷新会重新计数；同一路径的重复 PJAX/主题事件与语言切换不重复上报。本地/IP 预览不请求统计，失败或超时显示“—”。未使用本地存储模拟全站访问次数。

原始契约依据为 `https://www.busuanzi.cc/doc.php`、`https://cdn.busuanzi.cc/busuanzi/3.6.9/busuanzi.min.js`。前端自行读取其 POST JSON，只发送去掉查询参数和片段的页面地址与来源域名，不加载第三方脚本或发送 Cookie。统计服务对域名的接入限制以其公告为准。

已通过 ESLint、Stylelint、TypeScript、22 项相关单元测试及完整 Vite/Hexo 构建（119 个文件）。17 个 HTML 中，16 个有页脚的页面均恰好有一个统计组件；独立 404 页面没有页脚，不添加计数。

桌面和 Pixel 7 模拟器共 4 项浏览器测试通过，验证数值读取、双主题、真实可视区域、语言切换、PJAX 去重、503 失败与本地预览排除。结果及整屏截图见 `test-results/footer-visits-accepted/`；截图计数来自固定测试响应。手机原有视觉视口偏移会使元素局部截图空白，整屏截图与可视区域断言确认内容正常，无需扩大修改范围。

本地首页及 `/posts/speedtest-architecture/` 均 HTTP 200。实际公网统计数据尚未验收：本地地址不受服务支持，本次对本地地址的外部 API 探测超时，不能据此宣称公网接口可用；发布到受支持的正式域名后需核验真实数据。现有历史数据以该服务记录为准，未接入期间的访问无法补回。
